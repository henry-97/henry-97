### [Mine App · 应用管理器](https://github.com/henry-97/MineApp)

<p>
  <a href="https://github.com/henry-97/MineApp/releases/latest"><img alt="release" src="https://img.shields.io/github/v/release/henry-97/MineApp?color=0F6E56"></a>
  <img alt="size" src="https://img.shields.io/badge/APK-550KB-0F6E56">
  <img alt="license" src="https://img.shields.io/badge/license-GPL--3.0-0F6E56">
</p>

一款专让卡顿安卓设备焕发活力的纯净应用管理器。

- **真·零依赖** —— 无 Gradle 冗余，不依赖 Root，无需常驻 Shizuku，APK 不足 1 MB
- **AOT 预编译** —— 走 `cmd package compile` 做全量静态编译，消除 JIT 卡顿
- **三套独立开关** —— 归档冻结 / 后台限制 / 电源白名单，互不覆盖，精确到单个应用

[看项目](https://github.com/henry-97/MineApp)　·　[下载最新版](https://github.com/henry-97/MineApp/releases/latest)
